# Deep Learning Course Examples
Baylor University, Department of Electrical and Computer Engineering

## Introduction to Deep Learning

Course Examples in TensorFlow and PyTorch:

1. **ML_Examples**: Linear Regression, Logistic Regression, Neural Networks
2. **CNN_Examples**:  Convolutional Neural Networks
3. **RNN_Examples**:  Recurrent Neural Networks
4. **DRL_Examples**:  Deep Reinforcement Learning
5. **GAN_Examples**:  Generative Adversarial Networks

## What's new — ELC 5365 Spring 2026

A fresh suite of PyTorch demos for the Deep RL lecture has been added to
[`DRL_Examples/`](DRL_Examples/) — ten self-contained scripts covering
**DQN, Double DQN, Dueling DQN, PER-DQN, REINFORCE, A2C, PPO, DDPG, TD3,
and SAC**. Each demo trains silently and pops up a live pygame window
for periodic class visualizations (baseline → checkpoints → final
showcase). See
[`DRL_Examples/README_DRL_Examples.md`](DRL_Examples/README_DRL_Examples.md)
for the full description and suggested classroom order.
